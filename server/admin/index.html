      Settings

      ETA = drive time along real roads + typical collecting time at each stop before the resident's.
      Stop radius: how close the truck must be to count as "at" a stop. Default time per stop: for stops with no collection history yet. Road refresh: how often the road from each moving truck to its next stop is re-fetched. Average car speed: rough drive times if the route server can't be reached (shown under Alerts). Search country code: narrows the resident app's location search.
